# Thatch & Timber

Ein kleines Aufbauspiel im Browser, inspiriert von den ersten „Die Siedler"-Teilen.
Dorf gründen, Holz und Stein ernten, Bretter sägen, Felder bestellen, Erz schmelzen,
Handel treiben — vom Weiler bis zur Stadt.

**Spielen:** https://mbohnenkamp.github.io/thatch-and-timber/

Läuft direkt im Browser, nichts zu installieren. Spielstände bleiben im eigenen Browser.

## Feedback

Fehler gefunden, Idee gehabt, irgendwo hängen geblieben? Gern als
[Issue](https://github.com/mbohnenkamp/thatch-and-timber/issues) — auch kurz und formlos.

## Selbst starten

```bash
npm install
npm run dev
```

Gebaut mit [Three.js](https://threejs.org) und [Vite](https://vite.dev).
